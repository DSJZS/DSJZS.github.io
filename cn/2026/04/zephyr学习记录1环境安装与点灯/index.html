前言

最近开始折腾 Zephyr 了，这篇文章就是用于介绍怎么安装并点灯。

开发板还是经典的蓝皮 STM32F103C8T6 最小系统开发板。

环境安装

这一块最权威的还是官方文档的 Getting Started Guide。照着文档中说的做就行。

主要阅读下面几个章节：

  • Select and Update OS
  • Install dependencies
  • Get Zephyr and install Python dependencies
  • Install the Zephyr SDK

点灯测试

将环境安装推荐阅读的几个章节阅读完成并照着做之后，环境问题就解决了。

接着阅读 Getting Started Guide。

主要阅读下面几个章节：

  • Build the Blinky Sample
  • Flash the Sample

值得注意的是 Build the Blinky Sample 中 <your-board-name> 需要改成蓝皮 STM32F103C8T6 最小系统开发板。具体到底是不适配，名字叫什么可以通过 Supported Boards and Shields 手册查询。

我已经帮你们查询到了，为 stm32_min_dev。

根据 Build the Blinky Sample 章节的提示。在 Ubuntu 等 Linux 系统下终端中输入下面的命令即可：

west build -p auto -b stm32_min_dev@blue samples/basic/blinky

然后接上 STLINKv2 等调试器，并按照 Flash the Sample 章节所说的执行后，开发板 PC13 引脚连接的 LED 灯会闪烁(最小系统板的这个引脚一般都会自带一个绿色或者其它颜色的LED接着)。
