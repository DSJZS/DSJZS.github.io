前言

这篇文章用于记录如何使用 vscode 开发 zephyr 项目。

开发板还是经典的蓝皮 STM32F103C8T6 最小系统开发板。

环境搭建

新建一个 vscode 配置文件，然后按照 zephyr 项目官方的 Visual Studio Code 使用手册 安装插件即可。

创建一个空项目

我研究了半天，west 工具貌似没有对应的功能，只能手动复制示例项目然后删除不必要的部分做空项目。

比如工作空间中 zephyr/samples/hello_world 就比较合适，因为它基本上就是空的，只有一个 “hello world” 打印函数。

执行下面的指令就可以创建一个空项目，然后编译并烧录测试了

cp -r zephyr/samples/hello_world ./demo
cd ./demo
west build -b stm32_min_dev@blue
west flash

然后使用你常见的串口工具，或者 socat 之类的通用工具观察 MCU 串口输出即可。

结尾

使用 vscode 编译一个基础的程序然后烧录还是简单，主要还是配合其它的工具比较麻烦。

不过我突然发现官网还推荐一个基于 vscode 的工具 Workbench for Zephyr，有空我再研究一下。
