知识点

桶排序

桶排序（Bucket Sort）的思路是：先按照某种映射规则，把元素分到若干个桶里；再分别对每个桶排序；最后按照桶的顺序把结果合并起来。

它适合以下情况：

  • 元素能够映射到一个确定的区间中。
  • 数据范围已知，或者能够先求出最大值和最小值。
  • 数据分布比较均匀，不会让大量元素都挤在同一个桶中。
  • 可以接受额外的空间开销。

假设有 nnn 个元素、bbb 个桶，第 iii 个桶中有 mim_imi​ 个元素，那么桶排序的时间复杂度取决于桶内使用的排序算法。下面的模板使用插入排序，时间复杂度为：

O(n+b+∑i=1bmi2) O\left(n + b + \sum_{i=1}^{b}m_i^2\right) O(n+b+i=1∑b​mi2​)
  • 数据分布均匀、桶的数量和大小设置合理时，平均时间复杂度可以达到 O(n+b)O(n + b)O(n+b)；当 bbb 与 nnn 同阶时，通常记为 O(n)O(n)O(n)。
  • 所有元素都落入同一个桶时，会退化为 O(n2)O(n^2)O(n2)。
  • 需要保存所有桶，空间复杂度为 O(n+b)O(n + b)O(n+b)。

下面是一个支持负数的整数桶排序模板。bucketWidth 表示每个桶覆盖的数值范围，需要根据数据分布选择；它必须大于 0：

#include <algorithm>
#include <cstddef>
#include <stdexcept>
#include <vector>

void bucketSort(std::vector<int>& nums, int bucketWidth) {
    if (nums.size() < 2) {
        return;
    }
    if (bucketWidth <= 0) {
        throw std::invalid_argument("bucketWidth must be positive");
    }

    const auto [minIt, maxIt] = std::minmax_element(nums.begin(), nums.end());
    const long long minValue = *minIt;
    const long long maxValue = *maxIt;
    const std::size_t bucketCount =
        static_cast<std::size_t>((maxValue - minValue) / bucketWidth + 1);

    std::vector<std::vector<int>> buckets(bucketCount);
    for (int value : nums) {
        const std::size_t index =
            static_cast<std::size_t>((static_cast<long long>(value) - minValue) /
                                     bucketWidth);
        buckets[index].push_back(value);
    }

    std::size_t writeIndex = 0;
    for (auto& bucket : buckets) {
        // 对桶内元素使用插入排序
        for (std::size_t i = 1; i < bucket.size(); ++i) {
            const int value = bucket[i];
            std::size_t j = i;
            while (j > 0 && bucket[j - 1] > value) {
                bucket[j] = bucket[j - 1];
                --j;
            }
            bucket[j] = value;
        }

        for (int value : bucket) {
            nums[writeIndex++] = value;
        }
    }
}

在前 K 个高频元素中，不是按照元素值分桶，而是按照元素出现的次数分桶。一个元素最多出现 nnn 次，因此可以创建 n+1n + 1n+1 个桶，把出现次数为 frequency 的元素放入 buckets[frequency]，再从后向前遍历桶。这样不需要对频次排序，时间复杂度和空间复杂度都是 O(n)O(n)O(n)。
