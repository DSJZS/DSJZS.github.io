语法

文字编辑

标题

# text
## text
### text
#### text
##### text
###### text

这里 # 的数量表示了标题的级别，一般最多支持六级标题。

高亮

==text==

这个高亮看平台是否支持。

很多平台我看着不支持。

加粗

**text**
__text__

斜体

*斜体*
_斜体_

斜体有两种写法，如上。

删除线

~~text~~

删除线的写法如上。

我的博客给删除线的显示效果修改成黑幕了，如下。

秘密

我觉得这样的效果比较好，也比较方便。

链接

[text](uri)
[text](#topic)

链接提供类似超链接的作用。

可以跳转到一个 uri 或者本文的某个标题或者组合起来也行。

列表

无序列表(Bullet List)

- item 1
- item 2
	- item 2-1
	- item 2-2 
		- item 2-2-1

无序列表不分前后，可以依靠缩进表示上下关系。

有序列表(Numbered List)

1. item1
2. item2
	1. item 2-1
	2. item 2-2
		1. item 2-2-1

有序列表分前后，可以依靠缩进表示上下关系。

待办事项(可选框)

- [ ] task 1
- [ ] task 2
	- [ ] task 2-1
	- [ ] task 2-2
		- [x] task 2-2-1

[ ] 左右方括号中间一个空格表示不选择。

[x] 左右方括号中间一个 x 或者 X 表示选择。

可以依靠缩进表示上下关系。

引用(Quote)

> quote 1
> quote 2
> > quote 2-1
> > quote 2-2
> > > quote 2-2-1

可以依靠缩进表示上下关系。

我在博客中一般用于引用一个具体的作品或者表示某人说的话。

图片

![text](/path/to/image)

text 表示插入图片的描述文本，根据平台的不同，处理方式也不同。一般显示在图片下方。 /path/to/image 表示图片资源的路径。

表格

| head 1 | head 2 | head 3 |
| ------ | ------ | ------ |
| 123    | 456    | 789    |
| 321    | 654    | 987    |

第一行是每列的 head 文本，第二行固定为 - 。

后面几行为每列的具体内容。

注释(footnote)

注释[^1]
[^1]: this is a footnote

注释文本在编辑的过程中不一定要在最下方。

但是最终的显示效果，其会自动编排在文章的最下方。

还有一些其它的注释语法，不过不通用，这里不介绍了。

标注(callout)

> [!NOTE] title
> text 1  
> text 2

这种标注一般看平台，每个平台的规则不太一样。

比如 NOTE 大部分平台都支持，但是其它比如 Example 之类的可能就有问题。

这里不多介绍，建议查询对应的文档。

比如 Obsidian 就有官方文档介绍它支持那些。
