前言

也是好久没有更新博客了，最近一直比较忙，没有什么动力更新，也不知道说些什么。近几天有空，正好更新一下站点，说说有什么变化的地方以及我的一些想法。

对于博客开发记录这个新系列，我也说不准它到底算教程、站点更新日志，还是单纯对自己网站的吐槽——可能都有吧。也许今天这篇只是记录，下一篇就成了教程呢。

总之，只要我对博客站点做了什么修改，就会在这里写一篇博客开发记录，权当给自己留个档，也顺便给可能有同样需求的人一个参考。

变化的说明与缘由

先说一下站点的变化吧，如果你之前来过我的博客，你会看到这样的主页：

2026年7月前博客的主页

可以看到老主题是 hugo-stack ，比较花里胡哨。我还加了一堆 Page ，音乐播放器等功能。一开始我感觉挺好的，这个主题支持给很多地方插入图片，可以让主页变得很酷炫，播放器啥的再放些萌萌哒 (死肥宅喜欢听的) 的歌曲，让别人一进来就知道这是一个程序猿/二次元 (死肥宅) 的网站。

后来为什么我想更换主题了？有很多原因吧，首先我发现自己并没有那么二次元 (但还是死肥宅) 。一开始我看某个动漫/电影/游戏之类的我是主动去了解去找资源去看，全看个人兴趣，哪怕别人说这是一个烂作，我喜欢的话我也会看好几遍，去论坛上找人聊天。后面或许是近期二次元作品同质化太严重了太无聊了，又或许是受到外界的影响吧，逐渐变得随大流了，那些主播在新番导播里说好看或者群里大家都在传我才会跟着别人去看。我发现自己的爱好或许和大众不一样，我还是喜欢传统王道剧情，主角是一个乐观开朗 (的幸运色狼)，在冒险的途中逐渐结交伙伴和收集道具，不断的遇到困难最后完成xx伟业之类的。看着很俗套吧？但我感觉很多经典的游戏(比如RPG，尤其是JRPG)都是这样的。我看着会很放松很喜欢，我向往这样的生活，因为我的日常似乎什么也收集不了呢……我办好一个任务，没有新伙伴也没有道具奖励我，也就是说没有什么正反馈。而且任务一般都是一些无聊的杂活，拯救世界什么的不存在了。总之，最近的一些萌萌哒/百合/苦大仇深的乐队番，还有在店后面抽烟啊之类我根本看不下去。也不是拉踩，实话实说就和我小时候看别人讨论《花千骨》很好看一样，我真去X奇艺搜了去看，就没怎么看懂……我应该不是他们的受众吧 😂😹

还有一个更换主题的原因就是不好用，原来的主题说实话一页显示的博客数量啥的都很少，纯粹是为了显示图片啥的做的取舍，但是我又没那么多的图片加到博客的封面吸引读者 (死肥宅) 用。还有“更新日志”、“留言板”、“链接”，“归档”等 Page 说实话分的太细了，看着很乱，不如直接合并到 “关于” 等 Page 中。音乐播放器等功能也是，真的有人去别人的博客是为了听音乐吗？可能有吧，但我相信来看我博客的大部分都是来学习技术的吧 (总不可能是死肥宅吧) ，这个播放器功能只会让页面加载的速度变慢，所以我直接去除了。

删掉无用功能的同时我也新加了一些功能，详情见新增与更改的内容小节。

总之，如今的博客风格为极简主义，我目前很喜欢。

2026年7月后博客的“关于”页面

新增与更改的内容

  1. 更换了主题。主题由 hugo-stack 变为 hugo-paged 。
  2. 添加了 home 与 about 两个 Page ，用于介绍站点和我本人，还有一些老 Page 的功能合并到这两个里面了。
  3. 添加了 todo 页面，用于记录待办事项。主要起到监督与求助的作用。
  4. 初步支持国际化。目前支持中文和英文，但还是以中文为主，英文会少内容。
  5. ~~text~~ 现在不是给文本加删除线了，而是加黑幕。比如 text 。
  6. 找 bing 收录我的博客了。没找百度是因为要收集一些信息，懒得给。google 则是要单独买个域名才能收录，后面再加吧……
  7. 支持静态网页的加密。用于加密一些 不可告人的 内容。(还不稳定，暂时取消)。

展望

将来可能从单纯的博文发布网站转为一个真正的个人网站，除了公布公布博客，还会公布一些我其它类型的个人作品，比如绘画啥的。

也就是说今后发布的内容会有更多记录生活的部分，而非纯粹的技术总结之类的( 虽然现在就有屋里食研之类的博客了 )。

希望越来越多的同好关注我！

Good Time Good Life!
