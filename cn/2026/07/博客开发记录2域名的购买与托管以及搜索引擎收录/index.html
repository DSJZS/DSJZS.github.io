前言

今天整了个域名 masterji.top 给博客做自定义域名了。

为什么非要整个域名了？我在博客开发记录(1)中有提到过，因为 Google Search Console 貌似无法抓取 https://dsjzs.github.io/sitemap.xml 之类的站点地图，一定要买个域名然后抓取 https://masterji.top/sitemap.xml 之类的才行，所以我就整了个域名。

这篇文章用于记录购买域名、托管域名、设置Github Pages自定义域名以及让搜索引擎收录博客网页的过程和遇到的问题。

购买域名

我推荐使用 NameSilo 进行域名注册。只要不是特别稀有的域名，价格都挺便宜，花个 1~2 美元就能直接租一年了。

详细的流程观看这篇文章就行了。

托管域名

购买了域名后，如果你的域名注册商不提供托管服务( 比如上面我推荐的 NameSilo )，那么你还需要找一个第三方 DNS 托管商将你购买的域名放到他们的域名服务器进行托管。

一般推荐添加域名到 Cloudflare 进行托管，因为对个人而言，Cloudflare 的服务基本上是免费的。

详细的流程观看这篇文章就行了，和上一步的推荐文章是同一个作者，都是以 NameSilo 购买域名为例。

配置 Github Pages 遇到的常见问题

Enforce HTTPS 无法开启

如果你的 Custom domain 配置后果没有显示绿色的 DNS check successful，显示 Domain's DNS record could not be retrieved. For more information, see documentation (lnvalidDNSError) 或者 Enforce HTTPS 为灰色不能勾选，那么建议关闭 Cloudflare DNS 记录中的代理加速，并重新配置 Custom domain 。

博客更新后 Custom domain 配置失效

如果你发现每次博客更新后，Github Pages 的 Custom domain 配置失效/不见了，参考这篇文章，在 static/CNAME 中写下你配置的域名。
