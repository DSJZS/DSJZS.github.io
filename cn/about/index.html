我是谁？

中文昵称「成元」「元神」，英文 ID「Oyuanzi」「yuangod」。

一个因为各种原因全国到处跑的足智多谋湖北人，在各个城市充当 NPC 。作为一个刚入行的嵌入式初级码农主要活跃于 Github 和 BiliBili 。

爱好比较少，说得出来的正经爱好大概只有听音乐和玩棋牌/经营类游戏吧。进入大学后我几乎不再看电影、电视或娱乐节目，但伴随着写代码和写作会大量听歌，也爱看歌词（其实也喜欢吼两嗓子或者拿乐器演奏一下，但能力一般水平有限）。平时下班或者放假在家也会玩一下游戏王(主要是MASTER DUEL)、RimWorld、Minecraft之类的游戏。

总之，我会不定期的更新一些乱七八糟的博客，主要用于记录我学会了什么、对某些事物的看法还有一些 TODO 的东西。

我在博客中写的所有文字在遵守 CC 协议的前提下允许转载。

本站的架构

本站目前采用 Hugo 作为后台系统，网站创建之初的大半年一直使用 hugo-stack 主题，2026年7月至今转为使用 hugo-paged 主题并根据实际情况进行了些许修改。

本站采用了 Giscus 评论系统，需要用 GitHub 账号登录方可评论留言。不过由于一些意外，2026年7月前的评论貌似都没有了……

国际化部分暂时只支持中文和英文。实际应该是以中文为主，毕竟我没有那么多的时间去翻译/校对英文内容，在这方面有点不相信 AI。

更多关于本站的更新信息见站务分类或者博客开发系列下的文章。

最后提一下，本站头像（avatar）来自 Chinese Football 乐队《飞鱼转身》的 MV。
